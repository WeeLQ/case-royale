# CASE ROYALE — demo prototype

## Publish on GitHub Pages
1. Upload `index.html` to the root of your repository (same level as README).
2. Commit the file to the `main` branch.
3. In Settings → Pages select Deploy from a branch, `main`, and `/(root)`.
4. Wait for the Pages deployment to finish, then open the published URL.

## Important
This is a front-end demo only. It uses virtual CR coins and in-browser JavaScript.
Balances and inventory are not secure, are not synchronized between users, and may reset.
There are no deposits, cash wagers, withdrawals, or real Telegram gifts.
A real multiplayer Telegram Mini App requires a backend, Telegram WebApp validation,
database, server-side random outcomes, and a compliance review before any paid features.
